# OneTable Women — Event Website Prototype

A frontend prototype developed for a Fiverr client who wanted to rebuild their women’s social events community website.

The prototype explores a modern, polished, and responsive design for showcasing **events, community information, and membership opportunities**, while providing a foundation for a future private members area.

### Purpose

This prototype was created to demonstrate the initial **UI/UX direction and overall website experience** before moving forward with the complete platform.

### Tech Stack

* Next.js
* React
* Tailwind CSS
* JavaScript
* Google Antigravity — AI-assisted development and implementation
  

**Status:** Initial Client Prototype / MVP Concept
